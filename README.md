# 조잘조잘 (웹 시연판)

모임에서 같이 하는 대화 카드 앱 **조잘조잘**을 브라우저에서 바로 볼 수 있게 만든 시연용 웹 버전입니다.

**바로 실행하기 → https://episode-727.github.io/JAL-Web/**

설치 없이 링크만 열면 됩니다. 컴퓨터와 휴대폰 브라우저 모두에서 동작합니다.

- 컴퓨터: 화면 가운데 휴대폰 크기 틀 안에서 실행됩니다
- 휴대폰: 화면 전체가 앱이 됩니다
- 기록(검사 결과 · 앨범 · 혼자 조잘 · 꾸미기)은 그 브라우저 안에만 저장되고, 서버로 나가지 않습니다
- 컴퓨터 화면 오른쪽 아래 **처음부터 다시 보기**를 누르면 기록을 지우고 처음부터 다시 시작합니다
- 대기방의 QR 스캔은 카메라 대신 "데모 친구 추가" 버튼으로 친구를 불러옵니다

이 저장소에는 배포용으로 압축한 결과물만 있습니다.
